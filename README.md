# BrightClean — Cleaning Company Website Demo

A responsive website concept for a fictional cleaning company, created as part of my web development portfolio.

## Live Website
https://ritesh8328.github.io/brightclean/

## Project Overview
BrightClean demonstrates a clean, professional layout suitable for a small cleaning business.

## Features
- Navigation menu
- Hero section
- Three service cards
- About section
- Contact section
- Responsive CSS styling
- Footer section

## Technologies Used
- HTML5
- CSS3
- GitHub Pages for free hosting

## Purpose
This project was created for learning and portfolio demonstration. BrightClean is a fictional business, not a real company.
